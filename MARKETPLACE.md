**Tagline:** Provision Vendor reseller (MarketConnect-style) services from PeltyCMS orders

## Vendor reseller (MarketConnect-style) provisioning for PeltyCMS

Create, suspend, unsuspend and terminate customer services on Vendor reseller (MarketConnect-style) when orders are paid or cancelled. Credentials stay in Pelty secrets; the module runs as sandboxed WASM.

### Features
- Create / suspend / unsuspend / terminate
- Password + package sync hooks
- Works with Pelty product module mapping
- MythicCloud panel download supported

### Requirements
- Reachable Vendor reseller (MarketConnect-style) API/panel
- API token or login configured in Pelty
